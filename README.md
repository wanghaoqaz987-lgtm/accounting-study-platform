# 会计考证学习平台 📚

一个移动端优先的单页 HTML 学习应用，支持 **CMA**、**初级会计**、**PCMA 管理会计师** 三大证书备考。

## ✨ 功能

- 🏠 **首页**：考试流程指南 + 分阶段学习计划
- 📖 **题库练习**：80 道题（初级会计实务 / 经济法基础 / PCMA 四大模块 / CMA Part1 / Part2），即时反馈 + 详细解析
- 📝 **模拟考试**：限时答题、答题卡跳转、自动评分、错题回顾
- ❌ **错题本**：自动收录错题，支持错题重练与已掌握移除
- 👤 **学习统计**：正确率、连续学习天数、各科目进度

## 📱 使用

数据保存在浏览器 localStorage，无需服务器。直接用手机浏览器打开即可，推荐添加到主屏幕。

## 🚀 在线访问

部署到 GitHub Pages 后访问：`https://<用户名>.github.io/<仓库名>/`
